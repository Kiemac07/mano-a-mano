# Mano a Mano Boxing — Custom Glove Builder

This build keeps the existing layout and controls while replacing the old rough percentage/rectangle colour zones with template-aligned SVG panel paths based on the supplied clean glove artwork.

## Included
- Contest, Training and Sparring modes
- Lace and Velcro templates
- Left/right glove state
- Switch button changes between “Switch to right glove” and “Switch to left glove”
- Copy left design to right/both
- Existing colour palette, logo controls, custom text, enquiry form and pricing

The source artwork files in `assets/` are the supplied clean templates.
