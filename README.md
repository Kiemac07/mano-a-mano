# Mano a Mano Boxing — Custom Glove Configurator

This is the standalone final template-based configurator for the current Mano a Mano specification.

## Included
- Contest / Training / Sparring glove selection
- Contest: 8oz / 10oz / 12oz + Foam / Horsehair
- Training & Sparring: 14oz / 16oz + Full Foam / 3 Mix Horsehair Blend
- Training & Sparring: Laces / Velcro
- Supplied contest, lace and velcro template artwork
- Fixed Mano a Mano colour palette
- Panel-by-panel colour controls
- Logo colour controls
- £10 main-logo removal fee where permitted
- Free wrist-patch removal on applicable gloves
- Mandatory velcro logos, including Dangerous Adversary logo
- Independent left and right glove designs
- Copy left design to right glove
- Mobile-first responsive layout
- Design enquiry email to kieranmacmillan07@icloud.com

## Important
This build is a high-fidelity template-based customiser. It is not the future WebGL/GLB 3D configurator. The supplied final templates are used as the visual foundation so the configurator can be deployed and tested immediately. A true 360-degree 3D model can be swapped into the visualiser later without changing the product-option/state model.
